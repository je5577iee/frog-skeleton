# 蛙骨拼圖 Frog Skeleton Puzzle

以青蛙骨骼（背面觀）為主題的拼圖與名稱練習，適合大學普通生物學、動物學、比較解剖學課程，可以在實驗課解剖或觀察標本前預習，也可以在課後複習。

**整個遊戲只有一個 `index.html` 檔案，不用網路、不用安裝、不用註冊，也不會蒐集任何個人資料。**

## 線上使用

👉 https://je5577iee.github.io/frog-skeleton/

## 離線使用

下載 `index.html`，用瀏覽器打開即可，完全不需要網路。建議使用電腦操作（滑鼠拖曳最順手）；手機和平板也可以玩，用「先點骨頭、再點位置」的方式放置。

## 玩法

遊戲分成兩關，可以從首頁直接選。兩關都使用**最完整的版本**：56 塊骨頭、28 種名稱，頭骨也拆開。

### 第一關：拼骨架

- 把骨頭零件拖到骨架上正確的位置，也可以先點選骨頭，再點骨架上的位置
- 左右成對的骨頭可以放在任一邊；第 2～8 節軀幹椎也可以互換
- 放對會顯示中英文名稱與一句說明
- 同一塊骨頭放錯 3 次，會自動顯示正確位置；也可以按「提示位置」或「顯示輪廓」
- 拼完後可以直接接著挑戰第二關

### 第二關：標名稱

骨架已經拼好，要標出每一種骨頭的名稱（成對的骨頭只要標一邊）。有兩種方式可以選：

| 方式 | 玩法 |
|---|---|
| **拖曳標籤** | 把現成的名稱標籤拖到對應的骨頭上（也可以先點標籤，再點骨頭） |
| **自己打字** | 點一塊骨頭，打出它的名稱後按「確定」或 Enter；打錯兩次可以按「看答案」 |

自己打字時，**中文或英文都算對**，也接受常見的別名和簡體字，例如：
- 腸骨 / 髂骨 / ilium
- 橈尺骨 / 桡尺骨 / radio-ulna / radioulna
- 薦椎 / 骶椎 / sacral vertebra
- 蹠骨 / 跖骨 / metatarsals

標對的骨頭會依部位上色：頭骨、中軸骨、帶骨、前肢、後肢。完成後顯示用時、錯誤次數、看了幾次答案；拼骨架、拖曳標籤、自己打字的最佳時間會分開記在這台裝置。完成後點任何一塊骨頭都可以查看名稱與說明。

## 包含的骨頭

- **頭骨**：前頜骨 premaxilla、上頜骨 maxilla、方軛骨 quadratojugal、鼻骨 nasal、蝶篩骨 sphenethmoid、額頂骨 frontoparietal、前耳骨 prootic、外枕骨 exoccipital、鱗骨 squamosal
- **中軸骨**：寰椎 atlas、軀幹椎 presacral vertebrae（第 2～8 節）、薦椎 sacral vertebra、尾桿骨 urostyle
- **肩帶（背面）**：上肩胛骨 suprascapula、肩胛骨 scapula
- **前肢**：肱骨 humerus、橈尺骨 radio-ulna、腕骨 carpals、掌骨 metacarpals、指骨 phalanges
- **腰帶**：腸骨 ilium、坐骨 ischium
- **後肢**：股骨 femur、脛腓骨 tibiofibula、距骨 astragalus、跟骨 calcaneum、蹠骨 metatarsals、趾骨 phalanges

## 關於骨架圖

- 骨架為**原創示意圖**，以赤蛙屬（*Rana*）背面觀為範本，比例與形狀經過簡化，不能取代實體標本
- 只收錄**背面看得到**的骨頭；鎖骨、烏喙骨、胸骨、恥骨、副蝶骨、翼骨等主要在腹面的骨頭未列入
- 不同蛙種的骨骼細節（例如指骨數、橫突長度）會有差異
- 若發現名稱或位置有誤，歡迎提出 Issue
